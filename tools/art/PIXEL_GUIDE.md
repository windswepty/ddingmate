# 픽셀 그림 지침 (HUD 판·마스코트·효과)

다음에 캐릭터·효과를 그릴 때 먼저 읽는다. 공개 강좌들(맨 아래 출처)과
이 모드에서 실제로 해 보고 실패·성공한 기록(2026-10-22~23)을 합쳤다.

## 1. 순서 (전문 작업 흐름)

1. **참고 모으기**: 게임 속 같은 종류 그림의 크기·외곽선 색·눈 크기·색 수를 표로 적는다.
   - 서버 리소스팩(`$SP` 아래, 커밋 금지)은 `PIL`로 열어 색 수·bbox만 잰다.
2. **실루엣**: 한 가지 색으로 모양만 1배 크기로 찍는다.
   - 무엇인지 알아볼 수 없으면 세부를 더해도 안 된다.
   - 판 위에 얹힌 상태(밝은 판·어두운 판 둘 다)로 본다.
3. **덩어리 색**: 재질마다 기본색 하나로 칠한다.
   - 피부·머리·옷·소품은 서로 명도가 뚜렷이 달라야 한다(명도가 가독성의 1순위).
4. **명암**: 빛은 왼쪽 위 한 방향으로만 준다.
   - 재질마다 3단(밝음·기본·그늘)이 기본이고 많아도 5단이다.
   - 둥근 면도 한 면을 평평한 한 색으로 두고, 가장자리는 단순하게 둔다.
5. **외곽선**: 그림에서 가장 어두운 색으로 넣는다.
   - 셀렉티브 아웃라인은 맞닿은 부위 색을 어둡게 한 색이고, 빛 받는 쪽만 한 단 밝게 한다.
   - 순검정은 작고 움직이는 그림에서 가장 잘 읽힌다.
6. **다듬기**: 계단(jaggies) 중 모양을 망치는 곳에만 AA를 손으로 1~2칸 넣는다.
   - 자동 AA는 쓰지 않는다.
7. **실제 크기 검사**:
   - 1배·2배·게임 GUI 배율에서 본다.
   - 밝은 판과 어두운 판 위에서 본다.
   - 참고 그림과 나란히 놓고 본다.
   - 확대 화면에서만 예쁜 건 실패다.
8. **1명 시안 확인 → 나머지 → 전체를 한 장에 모아 일관성 검사**: 크기·외곽선·빛 방향·색 수가 같아야 한다.

## 2. 비율과 얼굴

**비율**
- SD는 2~2.5등신이다. 이 모드 마스코트는 머리가 그림의 2/3, 몸은 판에 가려지는 정도다.
- 메이플식 SD:
  - 머리와 머리카락이 키의 대부분을 차지한다.
  - 눈은 얼굴 아래쪽에 넓게 둔다.
  - 코는 생략하거나 1칸, 입은 아주 작게 한다.
- 눈을 얼굴 가운데에 두면 어른스럽고, 아래 1/3에 두면 귀엽다.

**눈 크기는 그림 크기에 따라**
| 그림 크기 | 눈 |
|---|---|
| 16×16 | 1×1 ~ 1×2 |
| 32×32 | 2×2 + 반짝 1칸 |
| 40×40 마스코트 | 4×5 (동물 NPC에서 승인) |

- 눈 속 칸이 많을수록 뭉개진다. 16칸 이하 그림에서는 동공·반짝을 다 넣지 않는다.
- 눈을 1칸 옮기면 표정이 바뀐다. 감정은 **눈 + 입만** 바꿔도 충분하다.
  - 웃는 눈 ∩
  - 반쯤 감은 눈
  - 윙크
  - 입 ω · D · ㅅ · 메롱

**애니메이션풍 눈**
- 윗속눈썹을 굵게 하고, 바깥 끝을 한 칸 길게 한다.
- 눈동자는 위가 짙고 아래로 밝게 한다.
- 반짝은 두 눈 모두 같은 쪽(왼쪽 위)에 둔다.
- 흰자는 바깥쪽에만 1칸 둔다.

**머리카락**
- 가닥이 아니라 **덩어리(clump)** 3~5개로 생각한다.
- 가마(정수리 뒤)에서 흐름선을 먼저 긋는다.
- 덩어리 끝은 뾰족한 1칸으로 끝내야 "머리카락"으로 읽힌다.
- 앞머리 끝이 같은 높이로 줄지어 있으면 빗(comb)처럼 보인다(사람 NPC 실패 원인). 길이·기울기를 다르게 하고 한쪽으로 쓸리게 한다.
- 윤기는 덩어리마다 짧은 밝은 획으로 넣는다. 정수리를 한 바퀴 도는 고리는 단조롭다.
- 머리 바깥 테두리를 밝히지 않는다. 그러면 흐려진다.

## 3. 색

**색 띠(ramp)**
- 재질마다 3~5단으로 만든다.
- 어두워질수록 색상을 차갑게(파랑·보라 쪽), 밝아질수록 따뜻하게(노랑·주황 쪽) 돌린다. 이를 hue shift라 하며, 한 단에 15~20°쯤이다.
- 명도만 바꾼 "곧은 띠"는 탁하고 다른 색과 안 어울린다.

**색 아끼기**
- 아주 어두운 재질(검은 머리·옷)은 2단 + 외곽선이면 된다.
- 금발·금장식은 피부의 어두운 단을 같이 써서 색 수를 줄인다.

**피하기**
- 순수 회색 그늘
- 보색끼리 평균 낸 탁한 AA 색
- 같은 그림 안에서 비슷하지만 다른 색 여러 개

## 4. 피해야 할 것 (흔한 실수)

| 이름 | 모습 | 고치기 |
|---|---|---|
| 필로 셰이딩 | 가장자리 따라 동심원으로 어두워짐 → 납작·흐릿 | 빛 방향 한쪽으로. 밝은 단을 가장자리까지 몇 군데 끌어낸다 |
| 밴딩 | 명암 단이 같은 길이로 나란히 계단을 이룸 | 단의 길이·위치를 어긋나게. AA를 1~2칸만 |
| AA 과다 | 테두리가 지저분·뭉개짐 | 꼭 필요한 계단만. 작은 그림일수록 AA를 줄인다 |
| 노이즈 | 1칸짜리 외톨이 점이 여기저기 | 같은 색은 2칸 이상 뭉치게(cluster) |
| 바깥 AA | 판 색이 바뀌면 테두리가 깨짐 | 바깥은 반투명 대신 외곽선으로 끝낸다 |
| 세부 과다 | 실제 크기에서 뭉개짐 | 실제 크기에서 안 보이는 건 지운다 |

## 5. 효과 (반짝이·빛·타격)

**반짝이**
- 크기별 모양:
  - 1칸
  - 십자 3칸
  - 십자 5칸 + 대각선 점 4개
  - 길쭉한 십자(세로가 김)
- 가운데는 흰색, 팔은 노랑에서 바깥으로 갈수록 투명하게 한다.
- 움직일 때는 작게 → 크게(번쩍) → 회전 → 사라짐으로 3~5프레임, 빠르게 보인다.

**빛·발광**
- 반투명 칸을 1~2겹 둘러 은은하게 퍼지게 한다.
- 효과 그림에서만 바깥 반투명을 허용한다.

**타격**
- 먼저 방사형 십자(starburst)가 번쩍인다(1프레임 흰색).
- 이어 파편·연기로 퍼진다.
- 짧을수록 손맛이 좋다.

**사용 원칙**
- 효과는 그림보다 밝고 채도가 높아야 눈에 띄지만, 한 장에 하나만 넣는다.
- 글자 가독성을 해치는 자리(판 가운데)에는 두지 않는다.
- 사용자 취향: 판 가운데는 깨끗하게. 케이크·촛불 같은 행사 장식은 빼고, 스킬은 각자의 그림으로.

## 6. 도구 (`tools/art`)

`px.py` 기능:
- 도형(`ellipse`·`rect`·`poly`)
- 층마다 명암(`shade`·`light`)
- 셀렉티브 외곽선
- 계단 반투명

**도형이 맞는 것:** 몸통·소품·판 장식처럼 둥근 덩어리. 동물 마스코트가 이 방식이다.

**직접 찍어야 하는 것:** 눈·입·머리 끝·사람 얼굴. 다음엔 아래처럼 ASCII 지도를 찍는 함수를 `px.py`에 더해서 쓴다.

```python
EYE = ['LLLLL',
       'LDDDD',
       'SWWDD',
       'SWDDI',
       '.IIIH']
def stamp(c, x0, y0, rows, pal, flip=False):
    for dy, row in enumerate(rows):
        for dx, ch in enumerate(row[::-1] if flip else row):
            if ch != '.':
                c.dot(x0 + dx, y0 + dy, pal[ch])
```

**검사표 스크립트**는 시안마다 한 장으로 만든다(`$SP`에).
- 1배·2배·8배
- 밝은 판·어두운 판
- 참고 그림을 나란히

`SendUserFile`로 보내 확인받는다.
