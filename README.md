# 띵메이트

띵타이쿤 온라인을 더 편하게 즐기도록 도와주는 Fabric 1.21.4 클라이언트 모드입니다. (비공식)

## 기능

### 🔔 일정 알리미
다음 서버 일정과 남은 시간을 화면 구석에 보여 주고, 미리 알려 줍니다.

| 일정 | 기본 알림 |
|---|---|
| 일일 초기화 (매일 03:00) | 10분 전 |
| 자정 초기화 (매일 00:00) | 15분 전 |
| 파라다이스 낚시 대회 (10:00 · 22:00) | 10분 · 1분 전 |
| 마을 투자 마감 (수 02:59) | 60분 · 10분 전 |
| 정기 점검 시작 · 종료 (수 09:00 · 15:00) | 30분 · 10분 전 / 종료할 때 |
| 주간 초기화 (목 03:00) | 60분 전 |
| 수렵꾼 호감도 초기화 (매월 1일) | 60분 전 |
| 내 마을 채널 재시작 | 화면 오른쪽 위 채널 표시를 읽어 지금 채널을 알아서 맞춰요 |

일정마다 켜고 끌 수 있고, 몇 분 전에 알릴지도 바꿀 수 있어요.

### 📦 재료 카운터
- 만들 레시피를 최대 3개 골라 두면, 재료가 얼마나 모였는지 HUD에 계속 보여 줍니다. (제작 · 가공 시설, 대형 제작대, 바리스타, 플로리스트, 가죽 공방, 형광 모루 등 17개 시설의 레시피 378개)
- **만들 개수**를 정하면 재료가 그만큼 곱해져요. [−] [+] [+10] [+64] 버튼으로 바로 바꿀 수 있고, 한 번에 여러 개 나오는 레시피는 "개 얻기"로 원하는 결과물 개수를 적으면 제작 횟수를 알아서 계산해요.
- 인벤토리는 실시간으로, **모험 가방**과 **아이템 저장소**는 한 번 열어 두면 기억해서 함께 셉니다.
- 모자란 재료가 다른 레시피로 만드는 것이면 필요한 원재료까지 보여 줍니다. (예: 조약돌 뭉치 → 조약돌)
- 재료가 다 모이면 알려 줍니다.

### 🛠️ 장비 내구도
고른 장비의 남은 내구도를 보여 주고, 얼마 안 남으면 알려 줍니다.

### 🎓 전문가 탭
전문가마다 쓸모 있는 기능을 한 탭에 모았어요.
- 바리스타 주문 도우미: 손님 주문 창 옆에 원하는 커피, 내가 가진 잔 수, 판매 합계를 보여 줍니다. 손님별 커피 가격표도 있어요.
- 요리 효율 순위: 밀키 상점 창을 열면 지금 요리 가격을 읽어, 원재료당 골드나 시간당 골드로 순위를 매겨요. 가격이 바뀌는 날(1·3·6·9…일 03시)이 지나면 지난 가격으로 표시해요.
- 제작 시간 스킬 레벨과 쉬프트 우클릭 스킬 타이머 설정도 여기 있어요.

### ⛏️ 전문가 스킬 타이머
쉬프트 우클릭 스킬(곡괭이 나가신다!, 쓸어담는 광질, 떡밥을 뿌려라! 등)을 쓰면 남은 지속 시간과 다시 쓸 수 있을 때까지 남은 시간을 HUD 에 보여 줍니다.
- /전문가 스킬 창을 한 번 열면 스킬마다 지금 레벨의 지속 시간 · 재사용 대기 시간을 읽어요. 강화하면 창을 다시 열 때 바뀐 값을 읽어요.
- 서버가 보내는 스킬 메시지(활성화 · 지속 종료 · 남은 쿨타임 · 사용 가능)로 시각을 맞춰요. 안 쓸 때는 HUD 가 숨어 있어요.

### ⚒️ 제작 완료 타이머
제작 · 가공 시설에서 제작을 시작하면 아이템마다 완료까지 남은 시간을 일정 HUD와 홈에 보여 주고, 다 되면 소리와 팝업으로 알려 줘요.
- 시설 창을 한 번 열면 레시피의 "제작 시간"을 배워서, 넣은 순서대로 하나씩 끝나는 시각을 계산해요.
- 같은 걸 여러 번 넣으면 "조약돌 뭉치 ×7 [3]" 처럼 한 줄로 묶고, 마지막 것이 끝날 때까지 남은 시간을 보여 준 뒤 한 번만 알려 줘요.
- 꺼내면 목록에서 알아서 빠져요. 향장품은 서버가 알려 주는 제조 시간으로 바로 맞춰요.

### ✅ 오늘 할 일
일일 의뢰 [0/5] · 주간 의뢰 [0/3] · 접속 시간 보상 받기 [0/6] · 마인리스트 추천 · 무역을 서버가 보내는 메시지로 **알아서 세요**(직접 체크하지 않아요). 다 하면 HUD 체크 상자에 ✓ 표시가 되고, 초기화 시각(매일 03시 · 목요일 03시 · 자정)이 지나면 다시 0부터 세요.
- 의뢰는 주간 의뢰 창에서 완료한 것만 주간으로, 나머지는 일일로 세요.
- 접속 시간 보상은 `/접속시간` 창을 열면 받은 보상 수로 맞춰요.
- 필요 없는 할 일은 [빼기]로 빼고 다시 넣을 수 있어요. 알아서 셀 수 있는 것만 넣을 수 있어요.

### ⏰ 접속 시간 보상
- 접속 1 · 2 · 3 · 4 · 5 · 8시간 보상 구간을 넘길 때마다 채팅으로 알려 줍니다.
- 게임에 들어가면 서버가 채팅으로 알려 주는 "일일 접속 시간"에 알아서 맞춰요. `/접속시간` 창을 열면 안 받은 보상 개수까지 보여 줍니다.

### 💬 키워드 알림
채팅에 원하는 단어가 들어간 메시지가 뜨거나, 다른 사람이 채팅으로 내 닉네임을 부르면 소리와 팝업으로 알려 줍니다.
- 설정: `/띵메이트` → **키워드** 탭에서 켜고, 단어를 쉼표로 구분해 적어요. (예: `오션오더, 풍선, 경매`)
- 예시: `[알림] 풍선이 근처에 도착했어요!` → 팝업 **채팅에 '풍선'** + 그 메시지
- 예시: `[칭호] 친구 : 닉네임 거기 있어?` → 팝업 **누가 내 닉네임을 불렀어요**
- 내가 쓴 채팅, 내 이름이 들어간 시스템 공지에는 울리지 않아요.

### 📜 알림 기록함
놓친 알림을 최근 100개까지 다시 볼 수 있습니다.

## 설치
1. [Fabric Loader](https://fabricmc.net/)와 [Fabric API](https://modrinth.com/mod/fabric-api)를 설치합니다.
2. 띵메이트 jar 파일을 `mods` 폴더에 넣습니다.
3. [Mod Menu](https://modrinth.com/mod/modmenu)가 있으면 모드 목록에서 바로 설정을 열 수 있어요. (선택)

## 사용법
채팅에 **`/띵메이트`** 를 입력하면 띵메이트 창이 열립니다. 모든 기능은 이 창에서 보고 바꿀 수 있어요.

처음 열면 **튜토리얼**이 28단계에 걸쳐 모든 기능을 하나씩, 해당 설정을 직접 짚어 가며 소개해 줘요(건너뛰기 가능, 홈의 "튜토리얼 다시 보기"로 다시 볼 수 있음). 홈 탭의 **"처음이세요?"** 안내도 따라 해 보세요. 각 탭 맨 위에 그 탭에서 할 수 있는 일이 적혀 있고, 설정에 마우스를 올리면 설명이 나와요.

- **홈**: 다음 일정, 오늘 접속 시간과 받을 보상, 할 일 진행, 재료 · 장비 현황을 한눈에 봅니다. 줄을 누르면 해당 탭으로 이동해요.
- **알림 방식 · 일정 · 내 채널 · 키워드 · 재료 · 장비 · 할 일 · 기록** 탭에서 각 기능을 설정합니다. 바꾼 값은 바로 적용돼요.
- HUD 모양(어두운 판 · 밝은 창 · 반투명), 진하기, **전체 크기(50~100%)**를 바꿀 수 있어요.
- **서버 HUD 피하기**(기본 켜짐): 구석 HUD가 서버의 재화 바 · 날짜/채널 줄과 채팅창을 가리지 않게 자리를 잡아요.
- **HUD 위치·크기 설정** 단추(알림 방식 · 재료 · 장비 · 할 일 탭): 게임 화면에서 HUD를 끌어 옮기고, HUD 위에서 마우스 휠을 굴리거나 오른쪽 아래 모서리를 끌어 HUD마다 크기(50~150%)를 바꿔요. 아래 가운데 [−] [+]로도 바꿀 수 있고, [저장]을 누르면 남아요. 오른쪽 클릭은 그 HUD를 원래 자리·크기로, [초기화]는 전부 원래대로, Esc는 취소예요.

Mod Menu의 설정 버튼이나, 조작 설정의 "띵메이트 창 열기" 단축키로도 열 수 있어요.
