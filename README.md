# 띵메이트

띵타이쿤 온라인을 더 편하게 즐기도록 도와주는 Fabric 1.21.4 클라이언트 모드입니다. (비공식)

## 기능

### 🔔 일정 알리미
다음 서버 일정과 남은 시간을 화면 구석에 보여 주고, 미리 알려 줍니다.

| 일정 | 기본 알림 |
|---|---|
| 일일 초기화 (매일 03:00) | 10분 전 |
| 자정 초기화 (매일 00:00) | 15분 전 |
| 세레니티 엔티티 초기화 (02:00 · 14:00) | 10분 · 3분 전 |
| 파라다이스 낚시 대회 (10:00 · 22:00) | 10분 · 1분 전 |
| 마을 투자 마감 (수 02:59) | 60분 · 10분 전 |
| 정기 점검 시작 · 종료 (수 09:00 · 15:00) | 30분 · 10분 전 / 종료할 때 |
| 주간 초기화 (목 03:00) | 60분 전 |
| 수렵꾼 호감도 초기화 (매월 1일) | 60분 전 |
| 내 채널 재시작 (마을 · 노크틸라 · 야생 · 아일랜드 · 스폰) | 채널 번호를 정하면 알려 줘요 |

일정마다 켜고 끌 수 있고, 몇 분 전에 알릴지도 바꿀 수 있어요.

### 📦 재료 카운터
- 만들 레시피를 최대 3개 골라 두면, 재료가 얼마나 모였는지 HUD에 계속 보여 줍니다. (제작 · 가공 시설 레시피 265개)
- 인벤토리는 실시간으로, **모험 가방**과 **아이템 저장소**는 한 번 열어 두면 기억해서 함께 셉니다.
- 모자란 재료가 다른 레시피로 만드는 것이면 필요한 원재료까지 보여 줍니다. (예: 조약돌 뭉치 → 조약돌)
- 재료가 다 모이면 알려 줍니다.

### 🛠️ 장비 내구도
고른 장비의 남은 내구도를 보여 주고, 얼마 안 남으면 알려 줍니다.

### ✅ 오늘 할 일
일일 의뢰 · 오션오더 · 미니보스 같은 할 일을 체크해 두면, 초기화 시각(매일 03시 · 목요일 03시 · 자정)에 알아서 풀립니다. 할 일은 자유롭게 추가 · 삭제할 수 있어요.

### ⏰ 접속 시간 보상
- 접속 1 · 2 · 3 · 4 · 5 · 8시간 보상 구간을 넘길 때마다 채팅으로 알려 줍니다.
- `/접속시간` 창을 열면 서버 기록에 맞춰지고, 아직 안 받은 보상 개수를 보여 줍니다.

### 💬 키워드 알림
채팅에 원하는 단어나 내 닉네임이 뜨면 알려 줍니다.

### 📜 알림 기록함
놓친 알림을 최근 100개까지 다시 볼 수 있습니다.

## 설치
1. [Fabric Loader](https://fabricmc.net/)와 [Fabric API](https://modrinth.com/mod/fabric-api)를 설치합니다.
2. 띵메이트 jar 파일을 `mods` 폴더에 넣습니다.
3. [Mod Menu](https://modrinth.com/mod/modmenu)가 있으면 모드 목록에서 바로 설정을 열 수 있어요. (선택)

## 설정
- **Mod Menu → 띵메이트 → 설정 버튼**
- 또는 채팅에 `/띵메이트 설정` (줄여서 `/알리미 설정`)
- 조작 설정의 "띵메이트"에서 설정 화면 · HUD 켜기/끄기 단축키를 정할 수 있어요.

설정 화면은 알림 방식 · 일정 · 내 채널 · 키워드 · 재료 · 장비 · 할 일 · 기록 탭으로 나뉘어 있고, 바꾼 값은 바로 적용됩니다.
HUD 모양(어두운 판 · 밝은 창 · 반투명), 위치, 진하기도 바꿀 수 있어요.

## 명령어
`/띵메이트` 대신 `/알리미`로 써도 됩니다.

| 명령어 | 내용 |
|---|---|
| `/띵메이트` | 도움말 |
| `/띵메이트 설정` | 설정 화면 열기 |
| `/띵메이트 목록` | 모든 일정과 다음 시각 |
| `/띵메이트 할일` | 오늘 할 일 |
| `/띵메이트 접속` | 오늘 접속 시간과 다음 보상 |
| `/띵메이트 기록` | 최근 알림 |
| `/띵메이트 가방` | 기록된 가방 목록 |
| `/띵메이트 테스트` | 알림 미리 보기 |
