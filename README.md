# 띵메이트 (ddingmate)

띵타이쿤 온라인을 위한 **비공식** Fabric 1.21.4 **클라이언트 전용** 모드입니다. 띵타이쿤 공식 제작물이 아닙니다.

- **일정 알리미**: 위키에 공개된 서버 일정을 화면 구석 HUD로 보여 주고, 정해진 시점에 소리·팝업·채팅(내 화면에만)으로 미리 알려 줍니다.
- **재료 카운터**: 핀으로 고른 레시피의 재료를 인벤토리와 열어 본 모험 가방에서 자동으로 셉니다.
- **키워드 알림**: 내 채팅창에 뜬 메시지에서 지정한 단어나 내 닉네임을 찾아 알려 줍니다.

하지 않는 것:
- 서버로 패킷·명령·채팅을 보내지 않습니다. 명령어 `/띵메이트`(줄여서 `/알리미`)는 내 클라이언트에서만 처리됩니다.
- 게임 조작을 대신하지 않습니다(자동 입력·자동 클릭 없음).
- 서버 정보를 따로 읽지 않습니다. 일정 알림은 PC 시계(한국 시간 기준)만 씁니다. 키워드 알림은 이미 내 채팅창에 표시된 메시지에 소리를 덧붙이기만 합니다.

> ⚠️ 띵타이쿤은 **화이트리스트 모드만 허용**합니다. 이 모드도 위키 [허용 모드]에 등재되기 전에는 서버에서 쓰면 제재(임시 정지) 대상이에요. 아래 "허가 신청" 절차를 먼저 밟으세요.

## 알려 주는 일정 (위키 [스케줄러] 등 기준, 한국 시간)

| `serenity_reset` | 매일 02:00·14:00 세레니티 엔티티 초기화 (덫·육식 동물·공룡 소멸) | 10·3분 전 |
| `fishing_contest` | 매일 10:00·22:00 파라다이스 낚시 대회 (10분 전 종목 공개) | 10·1분 전 |

## 재료 카운터

만들고 싶은 레시피를 핀(최대 3개)으로 고르고 몇 개 만들지 적으면, 재료가 얼마나 모였는지 HUD 에 계속 보여 줍니다.

- 레시피 265개: 위키 [제작 시설]·[가공 시설] 문서 기준 (`assets/ddingmate/recipes.json`)
- 내 인벤토리를 실시간으로 세고, **모험 가방**은 열었을 때 내용을 기억해 두었다가 합산합니다.
  - 띵타이쿤 리소스팩의 가방 창은 창 제목 속 글리프로 그려지고, 지금 열린 가방 번호 단추가 눌린 글리프로 들어 있습니다. 이걸 읽어 몇 번 가방인지 바로 압니다.
  - 리소스팩을 끈 경우 등에는 `ㄱ1`, `/가방 1` 처럼 번호가 붙은 단축어를 보낸 직후 열린 창을 그 번호의 가방으로 기록합니다(단축어는 설정에서 바꿀 수 있어요).
  - 번호 없이 열린 가방은 기록해 둔 가방들과 칸 배치를 비교해 찾습니다. 못 찾으면 기록하지 않습니다.
  - 가방을 대신 열거나 몰래 여는 일은 하지 않습니다. 가방은 서버에 있어서 **한 번씩 열어 둔 가방만** 합산됩니다.
  - 기록은 계정·서버별로 `config/ddingmate-bags.json` 에 저장됩니다.
- 서버 아이템(코룸 주괴 등)은 아이템 이름으로, 이름이 바뀌지 않은 바닐라 아이템은 아이템 종류로 셉니다.
- 재료가 다 모이면 한 번 알려 줍니다.
- 아이템 저장소는 아직 세지 않습니다.

## 디자인

띵타이쿤 설정 창의 디자인 규칙(둥근 회청색 창 #D4D9E0, 하늘색 머리 띠, 파란 분류 탭, 회청색 줄, 파란 ON·회색 OFF 스위치)을 따라 설정 화면·레시피 고르기·HUD·알림 팝업을 그립니다.

- 서버 리소스팩 그림·로고는 쓰지 않고 색 면과 바닐라 아이템 아이콘으로 직접 그렸습니다. 창에는 "비공식" 표시가 있습니다.
- 글꼴: 띵타이쿤과 같은 **갈무리(Galmuri9 본문 · Galmuri11 Bold 제목)** 를 넣었습니다. 갈무리는 이민서(quiple) 님의 글꼴로 SIL OFL 1.1 로 배포되며, 원본 파일과 라이선스(`src/main/resources/LICENSE-Galmuri-OFL.txt`, jar 안에도 들어감)를 그대로 담았습니다. 설정에서 끌 수 있습니다.
- HUD 스타일: 어두운 판(서버 HUD 풍, 기본) · 밝은 창 · 반투명(예전 검은 상자), 진하기 30~100%.
- HUD 는 화면 구석에만 그리고(서버 HUD·NPC 말풍선이 쓰는 위 가운데는 비움), 길어지면 채팅창을 가리지 않게 옆으로 넘어갑니다.

## 설정 화면

모든 설정을 버튼으로 켜고 끌 수 있어요. 여는 방법은 세 가지예요.

- **Mod Menu → 띵메이트 → 설정(톱니) 버튼**
- 조작 설정 → "띵메이트" → "설정 화면 열기" 키 (기본은 비어 있음)
- `/띵메이트 설정` (또는 `/알리미 설정`)

탭 구성:
- 알림 방식: 일정 HUD, 소리, 팝업, 채팅 알림, 소리 크기, HUD 위치·일정 수·스타일·진하기
- 일정: 14개 일정 각각 켜기/끄기 + 몇 분 전에 알릴지 (마우스를 올리면 설명이 나와요)
- 내 채널: 마을·노크틸라·야생·아일랜드·스폰 채널 번호 (클릭하면 다음 번호, 오른쪽 클릭·Shift+클릭은 이전 번호)
- 키워드: 켜기/끄기, 내 닉네임 언급, 키워드 목록(쉼표로 구분)
- 재료 카운터: 핀 3개(레시피 검색·시설별 거르기) + 만들 개수, 카운터 HUD·가방 합산·위치·완료 알림, 가방 단축어, 가방 기록 지우기

바꾼 값은 바로 적용되고, 화면을 닫을 때 저장돼요.

## 명령어 (설정 화면과 같은 기능, `/알리미` 로 줄여 써도 됨)

```
/띵메이트                     도움말
/띵메이트 목록                 모든 일정과 다음 시각
/띵메이트 hud|소리|토스트|채팅   켜고 끄기
/띵메이트 켜기|끄기 <id>        일정별 알림
/띵메이트 시점 <id> 10,3       몇 분 전에 알릴지 (0 = 지금)
/띵메이트 채널 마을 7          내 채널 재시작 알림 (0 = 끔)
/띵메이트 위치 좌상|우상|좌하|우하
/띵메이트 줄수 <1~10>
/띵메이트 키워드 목록|추가 <단어>|삭제 <단어>|켜기|끄기
/띵메이트 가방                 재료 카운터에 기록된 가방 목록
/띵메이트 테스트 · /띵메이트 다시읽기
```

HUD 켜기/끄기 단축키는 **기본으로 비어 있어요**. 서버 조작(Shift+F·F·Q·숫자키·Shift+휠)과 겹치지 않는 키를 조작 설정의 "띵메이트"에서 직접 지정하세요. 설정 파일은 `config/ddingmate.json` 입니다.

## 빌드·테스트

```bash
./gradlew build                # build/libs/ddingmate-0.2.0.jar
./gradlew runClientGameTest    # 싱글 월드를 만들어 HUD·명령어·알림을 자동 검사하고 화면을 캡처
```

## 허가 신청 (서버에서 쓰기 전에 꼭)

1. Modrinth에 프로젝트를 만들어 jar와 소스 공개 링크를 올립니다(위키 등재 조건).
2. 띵타이쿤 고객센터 → 일반 문의로 "자체 제작 모드 허용 모드 등재 요청"을 접수합니다. 포함할 내용:
   - 모드 이름·Modrinth 링크·소스 링크
   - 기능: 위키 공개 일정 HUD/알림, 내 채팅창에 표시된 메시지의 키워드 알림
   - 하지 않는 것: 서버 통신·자동 입력·정보 수집·게임 조작 없음, 클라이언트 전용
3. 등재(또는 디스코드 창작자료 공유 사전 허가) 확인 뒤에 서버에서 사용합니다.
