> 띵타이쿤은 **허용 모드 목록에 있는 모드만** 쓸 수 있어요. 띵메이트가 [위키 허용 모드](https://wiki.ddingtycoon.kr/ko) 목록에 올라가기 전에는 서버에서 쓰지 마세요. 등재 여부는 위키에서 직접 확인해 주세요.

# 띵메이트

띵타이쿤 온라인을 하면서 자꾸 놓치는 것들을 옆에서 챙겨 주는 클라이언트 전용 편의 모드예요.

- 🔔 **일정 알리미**: 초기화·점검·낚시 대회·내 채널 재시작을 화면 구석에 보여 주고 미리 알려 줘요.
- 📦 **재료 카운터**: 만들고 싶은 레시피를 고르면, 인벤토리와 모험 가방에 재료가 얼마나 모였는지 자동으로 세요.
- 💬 **키워드 알림**: 채팅창에 원하는 단어나 내 닉네임이 뜨면 소리와 팝업으로 알려 줘요.
- 🛠️ **장비 내구도**: 지정한 장비의 남은 내구도를 보여 주고, 얼마 안 남으면 알려 줘요.
- ✅ **오늘 할 일 · 접속 보상**: 직접 체크하는 할 일 목록이 초기화 시각마다 알아서 풀리고, 접속 1·2·3·4·5·8시간 보상 구간을 채팅으로 알려 줘요.
- 📜 **알림 기록함**: 놓친 알림을 나중에 모아 봐요.
- 🎨 **띵타이쿤풍 디자인**: 띵타이쿤 창과 어울리는 화면, 띵타이쿤과 같은 갈무리 글꼴을 써요.

---

## 🔔 일정 알리미

위키에 공개된 서버 일정을 기준으로, PC 시계(한국 시간)만 써서 계산해요.

| 일정 | 기본 알림 |
|---|---|
| 일일 초기화 (매일 03:00) | 10분 전 |
| 자정 초기화: 접속 보상·은행 한도 (매일 00:00) | 15분 전 |
| 세레니티 엔티티 초기화 (02:00 · 14:00) | 10분 · 3분 전 |
| 파라다이스 낚시 대회 (10:00 · 22:00) | 10분 · 1분 전 |
| 마을 투자 마감 (수 02:59) | 60분 · 10분 전 |
| 정기 점검 시작 · 종료 (수 09:00 · 15:00) | 30분 · 10분 전 / 종료할 때 |
| 주간 초기화 (목 03:00) | 60분 전 |
| 수렵꾼 호감도 초기화 (매월 1일) | 60분 전 |
| 내 채널 재시작 (마을 · 노크틸라 · 야생 · 아일랜드 · 스폰) | 채널 번호를 정하면 알려 줘요 |

- 일정마다 켜고 끌 수 있고, 몇 분 전에 알릴지도 바꿀 수 있어요.
- 알림은 소리 · 팝업 · 채팅(내 화면에만) 중에서 골라요.
- 화면 구석 HUD에 다음 일정과 남은 시간이 보여요. 10분 안이면 빨강, 1시간 안이면 노랑이에요.

## 📦 재료 카운터

1. 설정의 **재료** 탭에서 레시피를 골라 핀에 넣어요. 최대 3개까지 핀할 수 있고, 위키 제작 시설·가공 시설 레시피 265개 중에서 검색할 수 있어요.
2. 몇 개 만들지 적어요.
3. HUD에 재료마다 **모은 개수 / 필요한 개수**와 진행 막대가 떠요. 다 모이면 한 번 알려 줘요.

- 인벤토리는 실시간으로 세요.
- **모험 가방**은 한 번 열면 내용을 기억해 두었다가 합쳐서 보여 줘요. 몇 번 가방인지는 자동으로 알아내요.
- 가방은 서버에 있어서 **열어 본 가방만** 합산돼요. 모드가 가방을 대신 열어 주지는 않아요.
- **아이템 저장소**도 열었을 때 보관 개수를 기억해 합산해요.
- 모자란 재료가 다른 레시피로 만드는 것이면(예: 조약돌 뭉치) 필요한 원재료(조약돌)까지 한 단계 펼쳐 보여 줘요.

## 💬 키워드 알림

- 내 채팅창에 이미 뜬 메시지에서 지정한 단어를 찾아요. 기본 단어는 오션오더, 풍선, 청소예요.
- 다른 사람이 내 닉네임을 언급하면 알려 줘요.
- 내가 쓴 채팅에는 반응하지 않아요. 같은 단어는 10초 안에 다시 울리지 않아요.

## 🛠️ 장비 내구도

- 설정의 **장비** 탭에서 인벤토리에 있는 장비를 골라 켜면 HUD에 남은 내구도가 떠요.
- 정해 둔 %(기본 10%) 아래로 떨어지면 한 번 알려 줘요.

## ✅ 오늘 할 일 · 접속 시간 보상

- 일일 의뢰 · 오션오더 · 미니보스 · 바리스타 · 인피니티 타워 · 주간 의뢰 등을 직접 체크해요. 매일 03시 · 목요일 03시 · 자정에 알아서 풀려요. 할 일은 추가 · 삭제할 수 있어요.
- 일일 초기화 전에 남은 할 일을 알려 줘요.
- 오늘 접속 시간을 세어 위키 기준 보상 구간(1시간 루키 열쇠 ~ 8시간 골드하프)을 넘길 때 채팅으로 알려 줘요. 보상은 `/접속시간`에서 직접 받아요.

## 📜 알림 기록함

- 소리 · 팝업을 꺼 둬도 알림은 기록돼요. 설정의 **기록** 탭에서 최근 100개를 볼 수 있어요.

## 🎨 디자인

- 띵타이쿤 설정 창처럼 하늘색 머리 띠 · 파란 분류 탭 · ON/OFF 스위치로 꾸민 설정 화면이에요.
- HUD 스타일은 어두운 판(서버 HUD풍) · 밝은 창 · 반투명 중에서 골라요. 진하기도 조절할 수 있어요.
- HUD는 화면 구석에만 그려요. 서버 HUD와 NPC 말풍선이 쓰는 화면 위 가운데는 비워 둬요.

## ⚙️ 설정 여는 법

- **Mod Menu** → 띵메이트 → 설정(톱니) 버튼
- 조작 설정 → "띵메이트" → "설정 화면 열기" 키 (기본은 비어 있어요. 서버 조작과 겹치지 않는 키로 정해 주세요)
- 채팅에 `/띵메이트 설정` (줄여서 `/알리미 설정`)

## ✅ 하지 않는 것

- 서버로 패킷 · 명령 · 채팅을 보내지 않아요. `/띵메이트` 명령어는 내 게임 안에서만 처리돼요.
- 게임 조작을 대신하지 않아요. 자동 입력 · 자동 클릭 · 자동 이동이 없어요.
- 화면에 안 보이는 정보를 읽지 않아요. 내 인벤토리, 내가 연 창, 내 채팅창에 이미 보이는 것만 써요.
- 밝기(감마) · 투시 · 엑스레이 같은 기능은 없어요.
- 외부 서버와 통신하지 않아요. 레시피와 일정은 모드 안에 들어 있어요.

## 📋 필요한 것

- Minecraft **Java 1.21.4**, Fabric Loader 0.16 이상
- **Fabric API** (필수)
- **Mod Menu** (선택, 설정 버튼용. 띵타이쿤 허용 모드)
