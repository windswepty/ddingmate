제목: 자체 제작 모드 「띵메이트」 허용 모드 등재 요청

안녕하세요, 띵타이쿤을 즐기고 있는 [닉네임]입니다.
직접 만든 클라이언트 전용 편의 모드를 위키 허용 모드 목록에 올리고 싶어서 문의드립니다.

■ 모드 정보
- 이름: 띵메이트 (DdingMate)
- 버전: 0.3.0 / Fabric / Minecraft Java 1.21.4
- Modrinth: [Modrinth 주소]
- 소스 코드 공개: https://github.com/windswepty/ddingmate
- 필요 모드: Fabric API (Mod Menu 는 선택, 둘 다 허용 목록에 있음)

■ 기능
1. 일정 알리미
   - 위키에 공개된 일정(일일·자정·주간 초기화, 세레니티 초기화, 낚시 대회, 마을 투자 마감, 정기 점검, 수렵꾼 호감도, 채널 재시작)을 화면 구석에 보여 주고, 정해진 시간 전에 소리·팝업·채팅(본인 화면에만)으로 알려 줍니다.
   - 서버 정보를 읽지 않고 PC 시계(한국 시간)로만 계산합니다.
2. 재료 카운터
   - 위키 제작 시설·가공 시설 레시피 중 고른 것(최대 3개)의 재료를 본인 인벤토리에서 세어 "모은 개수/필요 개수"로 보여 줍니다.
   - 본인이 직접 연 모험 가방 창의 내용을 기억해 두었다가 함께 합산합니다. 가방을 대신 열거나 명령어를 보내지 않으며, 열어 본 가방만 셉니다.
3. 키워드 알림
   - 본인 채팅창에 이미 표시된 메시지에서 지정한 단어나 본인 닉네임을 찾아 소리·팝업으로 알려 줍니다.
4. 장비 내구도 표시
   - 본인이 고른 장비의 남은 내구도를 본인 인벤토리에서 읽어 보여 주고, 일정 % 아래로 떨어지면 알려 줍니다.
5. 오늘 할 일 · 접속 시간 보상 알림
   - 본인이 직접 체크하는 할 일 목록이며, 서버 초기화 시각(03시·목요일 03시·자정)이 지나면 체크가 풀립니다.
   - 본인 게임에서 접속 시간을 세어 위키의 접속 시간 보상 구간(1·2·3·4·5·8시간)을 넘길 때 채팅으로 알려 줍니다. 보상은 /접속시간 에서 본인이 직접 받습니다.
6. 알림 기록함
   - 위 알림들을 최근 100개까지 모아 볼 수 있습니다.
7. 아이템 저장소 합산
   - 본인이 직접 연 아이템 저장소 창의 보관 개수를 재료 카운터에 합산합니다.

■ 하지 않는 것
- 서버로 패킷·명령어·채팅을 보내지 않습니다. 모드 명령어(/띵메이트)는 본인 게임 안에서만 처리됩니다.
- 자동 입력·자동 클릭·자동 이동 등 게임 조작을 대신하지 않습니다.
- 화면에 보이지 않는 정보를 얻지 않습니다(투시·엑스레이·밝기 조절 없음). 외부 서버와 통신하지 않습니다.
- 보스바 영역(화면 위 가운데)에는 아무것도 그리지 않습니다.

■ 심사에 참고하실 점
- 모험 가방 번호는, 가방 창이 열릴 때 서버 리소스팩이 창 제목에 넣는 글자를 읽어서 알아냅니다. 글자가 없으면 본인이 보낸 가방 단축어(예: ㄱ1)를 읽기만 해서 판단합니다. 메시지를 막거나 바꾸지는 않습니다.
- 서버 리소스팩의 그림·글꼴 파일은 모드에 넣지 않았습니다. 화면은 직접 그렸고, 글꼴은 공개 라이선스(SIL OFL)인 갈무리 원본을 넣었습니다.
- 모드 설명과 화면에 "비공식 모드"라고 표시해 두었습니다.

등재가 어렵거나 고쳐야 할 기능이 있으면 알려 주세요. 바로 수정하겠습니다.
위키 등재가 어렵다면 디스코드 창작자료 채널 공유 허가 여부도 함께 여쭙고 싶습니다.

감사합니다.
